# Guía de sentimiento (ejemplo sintético)

Esta guía es un texto de prueba para el modo local; la vigente vive en
`docs/analytics/labeling/annotation_guideline.md`.

| Etiqueta | Cuándo |
| :--- | :--- |
| `NEG` | Queja, falla o molestia |
| `NEU` | Sin carga emocional clara |
| `POS` | Elogio o satisfacción |

* Si no se puede evaluar el texto, elige **No evaluable**.
